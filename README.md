# Nova Insight Dashboard

A clean, modern dark-mode analytics dashboard built as a lightweight static website.

## Preview locally

Open `index.html` directly in a browser, or serve it with a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – dashboard layout
- `styles.css` – dark theme styling and responsive layout
- `script.js` – small interactions for polished UI behavior

## Notes

This dashboard is designed as a public-facing demo with:
- KPI summary cards
- revenue trend chart
- audience donut chart
- top channel metrics table
- recent activity feed
- responsive layout for smaller screens
